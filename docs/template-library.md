# Biblioteca de referencias HTML

El proyecto incluye copias locales de las colecciones que el generador consulta para inspirar y clasificar diseños. La landing final se construye con el renderer propio; la presencia de una plantilla aquí no significa que su HTML, textos o imágenes se copien automáticamente al sitio generado.

## Fuentes incluidas

| Colección | Carpeta | Licencia y atribución |
|---|---|---|
| 100 Free HTML Templates | `plantillas/fuentes/100-free-html-templates/` | MIT. Se conserva `LICENSE` y la documentación de la fuente. Las imágenes conservan la atribución indicada por sus autores. |
| Novpix Free HTML Templates | `plantillas/fuentes/novpix-free-html-templates/` | MIT. Se conservan las licencias generales y las de cada plantilla. |
| UIUXLabz | `plantillas/fuentes/uiuxlabz/` | MIT según los archivos de cada repositorio/plantilla; se mantienen sus README y licencias. |
| Spicer Designs | `plantillas/fuentes/spicer-designs/` | CC BY 4.0 según las licencias incluidas por plantilla. Mantener el crédito a Spicer Designs y el enlace a la licencia al redistribuir o adaptar estos archivos. |
| Zadie | `plantillas/fuentes/zadie/plantillas/` | Las condiciones están documentadas por plantilla en sus README. Revisarlas antes de reutilizar o redistribuir una plantilla individual. |

Catálogos incluidos: `plantillas/uiuxlabz-catalog.json` y `plantillas/fuentes/zadie/zadie-catalog.json`.

Los materiales de terceros se incluyen como referencias locales. Las licencias y condiciones de cada fuente prevalecen sobre esta nota; verifica los archivos originales de licencia antes de publicar o entregar una página basada en ellos.
