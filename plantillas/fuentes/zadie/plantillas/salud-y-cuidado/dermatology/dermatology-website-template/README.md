# Clarity Dermatology - Free Website Template

A clean, clinical, and radiant website template designed for dermatology clinics and skin care practices. Built with pure HTML5 and CSS3.

## Pages Included

- **Home** (`index.html`) - Hero section, services overview, why choose us, testimonials, CTA
- **About** (`about.html`) - Clinic story, team profiles, core values, facility showcase
- **Services** (`services.html`) - Detailed service descriptions, pricing, new patient packages, insurance
- **Contact** (`contact.html`) - Appointment request form, contact info, FAQ, service area

## Quick Start

1. Download and unzip the template
2. Open `index.html` in your browser
3. Edit the HTML files to add your clinic's information
4. Replace placeholder colors with your own photos
5. Update contact details, hours, and location

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
  --primary: #0D9488;      /* Soft teal */
  --secondary: #E11D48;    /* Warm rose */
  --white: #FEFEFE;        /* Pure white */
  --off-white: #F8FAFB;    /* Light gray sections */
}
```

### Fonts
This template uses [Jost](https://fonts.google.com/specimen/Jost) for headings and [Figtree](https://fonts.google.com/specimen/Figtree) for body text, loaded via Google Fonts.

### Images
Replace the gradient placeholder areas with your own images. Image areas use `aspect-ratio` for consistent sizing.

## Features

- Fully responsive (mobile, tablet, desktop)

- CSS-only FAQ accordion
- Accessible form elements
- Reduced motion support
