# Diamond Shine Auto Wash - Website Template

A sleek, clean, and bold website template designed for car wash businesses. Built with pure HTML5 and CSS3.

## Quick Start

1. Download and extract the template files
2. Open `index.html` in your browser
3. Customize the content, colors, and images to match your business

## Pages

- **index.html** - Home page with hero, services overview, testimonials, and CTA
- **about.html** - Company story, team members, values, and facility details
- **services.html** - Wash packages with pricing, detailing services, monthly memberships, and fleet services
- **contact.html** - Contact form, business info, FAQ, and service area

## Customization

### Colors

Edit the CSS variables in `styles.css` under `:root`:

```css
--primary: #0284C7;      /* Electric blue */
--secondary: #06B6D4;    /* Bright cyan */
--navy: #0C1425;          /* Dark sections */
--white: #FAFCFF;         /* Background */
```

### Fonts

The template uses Google Fonts:
- **Russo One** for headings
- **Manrope** for body text

To change fonts, update the Google Fonts import URL and the `--font-heading` and `--font-body` variables.

### Images

Replace the placeholder areas with your own images. The `images/` directory is included for your photo assets.

### Content

All placeholder text is written for a car wash business. Replace the business name, address, phone number, hours, pricing, and service descriptions with your own information.

## Features

- Responsive design (mobile, tablet, desktop)
- Mobile navigation menu
- Pricing cards with featured tier highlighting
- CSS animations and hover effects
- Reduced motion support for accessibility
- Clean, semantic HTML5 markup
