# GreenLight Driving Academy — Free Website Template

A clean, friendly driving school website template. Forest green and amber palette, rounded typography, confidence-building layout. Built for driving schools serving teens and adult learners.

## License

Free to use for any personal or commercial project. Attribution appreciated but not required.

## Quick Start

1. Download and unzip
2. Open `index.html` in your browser to preview
3. Edit content directly in the HTML files
4. Replace placeholder colors/gradients with real photos

## Pages

- `index.html` — Homepage with hero, pass rate stats, programs overview, testimonials
- `about.html` — Academy story, instructors, fleet, state approval
- `services.html` — Course packages with pricing, add-on services
- `contact.html` — Enrollment form, contact info, FAQ

## Customization

### Business Details
Search and replace throughout all HTML files:
- `GreenLight Driving Academy` → Your school name
- `(555) 234-5678` → Your phone number
- `enroll@greenlightdriving.com` → Your email
- `456 Oakwood Boulevard` → Your address

### Colors
Edit CSS variables in `styles.css` under `:root`:
- `--primary` — Forest green (#2D6A4F)
- `--secondary` — Amber (#F59E0B)
- `--accent` — Blue (#2563EB)
- `--bg` — Light green tint (#F0FAF4)

### Fonts
Loaded from Google Fonts:
- **Varela Round** — Headings
- **Nunito Sans** — Body text

### Photos
Replace placeholder gradient divs with `<img>` tags pointing to your photos of instructors, vehicles, and students.

## Built With

- Pure HTML5 & CSS3
- Google Fonts
- Font Awesome 6.5.0 icons
- No JavaScript frameworks
