# Crestline Wealth Advisors — Free Website Template

A polished, authoritative financial advisor website template. Deep navy and aged gold palette, classical serif typography, whitespace-forward layout. Built for independent RIAs, CFPs, and wealth management firms.

## License

Free to use for any personal or commercial project. Attribution appreciated but not required.

## Quick Start

1. Download and unzip
2. Open `index.html` in your browser to preview
3. Edit content directly in the HTML files
4. Replace placeholder colors/gradients with real photos

## Pages

- `index.html` — Homepage with hero, services overview, philosophy, advisor preview, testimonials
- `about.html` — Firm story, advisor team, credentials, fee structure
- `services.html` — Full service offerings with descriptions and minimums
- `contact.html` — Consultation request form, FAQ, regulatory disclosures

## Customization

### Business Details
Search and replace throughout all HTML files:
- `Crestline Wealth Advisors` → Your firm name
- `(555) 678-9012` → Your phone number
- `info@crestlinewealth.com` → Your email
- `888 Harbor View Drive, Suite 400` → Your address

### Colors
Edit CSS variables in `styles.css` under `:root`:
- `--primary` — Deep navy (#1B2A4A)
- `--secondary` — Aged gold (#B8962E)
- `--accent` — Steel blue (#3E6B8F)
- `--bg` — Warm off-white (#FAFAF8)

### Fonts
Loaded from Google Fonts:
- **Petrona** — Headings
- **Source Sans 3** — Body text

### Regulatory Disclosure
Update the placeholder compliance disclaimer in the footer and contact page with your actual ADV, registration details, and legal disclosures.

### Photos
Replace placeholder gradient divs with `<img>` tags pointing to professional headshots and office photography.

## Built With

- Pure HTML5 & CSS3
- Google Fonts
- Font Awesome 6.5.0 icons
- No JavaScript frameworks
