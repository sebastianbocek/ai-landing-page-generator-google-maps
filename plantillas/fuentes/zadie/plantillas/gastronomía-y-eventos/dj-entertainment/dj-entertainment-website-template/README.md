# BassLine Entertainment — Free Website Template

A high-energy DJ and entertainment website template. Deep black background with electric purple and neon green accents, bold Bungee typography, pulsing animations. Built for DJs, entertainment companies, and performers.

## License

Free to use for any personal or commercial project. Attribution appreciated but not required.

## Quick Start

1. Download and unzip
2. Open `index.html` in your browser to preview
3. Edit content directly in the HTML files
4. Replace placeholder gradient backgrounds with real event photography

## Pages

- `index.html` — Homepage with hero, event types, genre grid, testimonials
- `about.html` — DJ profiles, equipment list, story
- `services.html` — Wedding, corporate, private party, club pricing with packages
- `contact.html` — Booking inquiry form, availability calendar placeholder, social links

## Customization

### Business Details
Search and replace throughout all HTML files:
- `BassLine Entertainment` → Your company name
- `BASSLINE` → Your brand name
- `(512) 555-0187` → Your phone number
- `book@basslineent.com` → Your email
- `Austin, TX` → Your city
- `@basslineent` → Your social handles

### Colors
Edit CSS variables in `styles.css` under `:root`:
- `--primary` — Electric purple (#7B2FBE)
- `--secondary` — Neon green (#39FF14)
- `--accent` — Hot pink (#FF3864)
- `--bg` — Deep black (#080808)

### Fonts
Loaded from Google Fonts:
- **Bungee** — Headings
- **Barlow** — Body text

### Photos
Replace the dark gradient placeholder divs with real event photos. Use images with high contrast and energy — dark venues with colorful lighting work perfectly with this design.

## Built With

- Pure HTML5 & CSS3
- Google Fonts
- Font Awesome 6.5.0 icons
- No JavaScript frameworks
