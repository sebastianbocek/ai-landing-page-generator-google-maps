# Canopy Tree Experts - Free Website Template

A professional, responsive website template designed for tree service companies, arborists, and tree care businesses.

## Features

- **4 Complete Pages**: Home, About, Services, Contact
- **Fully Responsive**: Mobile-first design that looks great on all devices
- **Pure HTML & CSS**: No JavaScript frameworks or build tools required
- **Accessible**: Semantic HTML, ARIA labels, and keyboard-friendly navigation
- **Fast Loading**: No heavy dependencies, optimized CSS

## Pages

1. **Home** (`index.html`) - Hero section, service overview cards, why choose us features, customer testimonials, and call-to-action
2. **About** (`about.html`) - Company story, core values, team profiles, and business stats
3. **Services** (`services.html`) - Detailed service descriptions with pricing, additional services grid, and 4-step process
4. **Contact** (`contact.html`) - Contact form with service selector, business info sidebar, emergency callout, hours, and FAQ

## Quick Start

1. Download and unzip the template
2. Open `index.html` in your browser to preview
3. Edit the HTML files to replace placeholder content with your business information
4. Upload to your web hosting provider

## Customization

### Colors

All colors are defined as CSS custom properties in `styles.css`. Update these values to match your brand:

```css
:root {
  --primary: #14532D;       /* Deep forest green */
  --secondary: #854D0E;     /* Bark brown */
  --accent: #F7FEE7;        /* Pale lime tint */
}
```

### Fonts

The template uses Google Fonts (Aleo for headings, Barlow for body text). To change fonts, update the `@import` URL and the `--font-heading` / `--font-body` variables.

### Content

- Replace all placeholder text with your actual business information
- Update phone numbers, email addresses, and physical addresses
- Adjust service descriptions and pricing to match your offerings
- Add your own team member information on the About page

### Images

Image placeholder areas use CSS gradients. Replace them with your actual photos by adding `<img>` tags or updating the background properties.
