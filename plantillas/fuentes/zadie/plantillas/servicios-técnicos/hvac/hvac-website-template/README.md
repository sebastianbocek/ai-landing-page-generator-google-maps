# ClimateControl Pros - HVAC Company Website Template

A professional, technical website template for HVAC companies, heating and cooling services, and climate control businesses.

## Features

- **Temperature Duality Design**: Cool blue to warm orange gradient theme representing heating and cooling services
- **24/7 Emergency Focus**: Prominent emergency contact information throughout
- **Service Categories**: Organized sections for cooling, heating, indoor air quality, and maintenance
- **Maintenance Plans**: Pricing table with tiered service plans
- **Trust Building**: Certifications, team profiles, and customer testimonials
- **Mobile Responsive**: Works on all devices
- **Pure HTML/CSS**: No JavaScript frameworks required

## Pages Included

1. **Home** - Hero with temperature display, services overview, trust badges, testimonials
2. **About** - Company story, team profiles, process steps, certifications
3. **Services** - Detailed service categories, emergency services, maintenance plans
4. **Contact** - Service request form with urgency levels, FAQ, service area

## Quick Start

1. Download and extract the template
2. Open `index.html` in your browser
3. Customize content in the HTML files
4. Modify colors in `styles.css` CSS variables
5. Deploy to any web host

## Customization

### Colors

Edit the CSS variables in `styles.css`:

```css
:root {
  --cool-blue: #2E86AB;
  --warm-orange: #F18F01;
  --ice-blue: #A8DADC;
  --slate: #3D4F5F;
  /* ... */
}
```

### Fonts

The template uses Google Fonts:
- **Titillium Web** - Technical headings
- **Nunito Sans** - Clean body text

### Content

Replace placeholder content:
- Business name and tagline
- Phone numbers and addresses
- Service descriptions and pricing
- Team member profiles
- Testimonials

## Deployment

This is a static HTML website. Deploy to:
- GitHub Pages
- Netlify
- Vercel
- Any traditional web host
