# Prestige Garment Care - Free Website Template

A refined, classic website template designed for dry cleaners, tailors, and garment care businesses. Built with pure HTML5 and CSS3.

## Pages Included

- **Home** (`index.html`) - Hero, services overview, why choose us, testimonials, CTA
- **About** (`about.html`) - Company story, values, team profiles, process steps
- **Services** (`services.html`) - Detailed service descriptions with pricing
- **Contact** (`contact.html`) - Contact form, business info, service area, FAQ

## Quick Start

1. Download and unzip the template
2. Replace placeholder content with your business information
3. Add your own images to the `images/` folder
4. Update contact details, hours, and location
5. Upload to your web hosting provider

## Customization

### Colors

Edit the CSS variables in `styles.css` under `:root`:

```css
--primary: #1E3A5F;      /* Navy blue */
--secondary: #C9A84C;    /* Champagne gold */
--ivory: #FAF8F0;        /* Background */
--charcoal: #1A1A2E;     /* Dark sections */
```

### Fonts

The template uses Google Fonts:
- **Cormorant** for headings
- **Source Sans 3** for body text

Change fonts by updating the Google Fonts link in each HTML file and the `--font-heading` / `--font-body` variables in CSS.

### Images

Replace the placeholder divs (`.photo-placeholder`) with actual `<img>` tags or background images. Recommended sizes:
- Hero image: 800x1000px
- Service images: 800x600px
- Team photos: 600x600px

## Features

- Fully responsive (desktop, tablet, mobile)
- Mobile hamburger menu
- CSS-only FAQ accordion
- Accessible markup with ARIA labels
- Eco-friendly solvents messaging
- Pickup and delivery scheduling form
